# Openloco

![Openloco](openloco.png)

This is a still very much work in progress reimplementation of Lego Loco. 
You need to have to orignal game installed because this project uses the original assets.

```
mkdir build && cd build
cmake -DCMAKE_BUILD_TYPE=DEBUG ..
./openloco <path to original installation directory>
```
